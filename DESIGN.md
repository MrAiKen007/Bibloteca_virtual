# Design System: Virtual Library Admin

## 1. Overview

**Creative North Star: "The Brand Command Center"**

The Admin Dashboard is a high-precision tool designed for speed and clarity, fully aligned with the Virtual Library's brand identity. It uses the platform's signature **Brand Red** as its primary accent, set against a sophisticated monochrome foundation.

**Key Characteristics:**
- **Unified Identity:** Adheres strictly to the platform's core palette (Red, Slate, White).
- **High-Precision Layout:** A sharp, technical interface that prioritizes data density and task efficiency.
- **Classic Typography:** Uses the brand's signature serif (Playfair Display) for headers and Inter for task-level UI.
- **Sharp Materiality:** Using 1px borders and tonal layering to define boundaries, matching the platform's "Sophisticated & Precise" personality.

## 2. Colors

The palette is anchored in the platform's vibrant Red and deep Slate neutrals.

### Primary
- **Brand Red** (#e84848): Used for primary actions, critical alerts, and brand highlights.
- **Red Hover** (#c93535): Darker shade for interactive states.

### Neutral
- **Deep Slate** (#1a1a1a): Primary text and sidebar background.
- **Slate 50** (#f8fafc): Main content area background.
- **Slate 200** (#e2e8f0): Border color for structured elements.

## 3. Typography

**Paired Families:** Playfair Display (Serif) & Inter (Sans)

### Hierarchy
- **Display** (700, 1.875rem, 1.2): Main page headings (Serif).
- **Headline** (600, 1.25rem, 1.3): Section headers and card titles.
- **Body** (400, 0.875rem, 1.5): Standard UI labels and data (Sans).
- **Label** (600, 0.75rem, uppercase): Metadata and badges.

## 4. Elevation

The system is "Flat-By-Default," relying on borders and tonal shifts for hierarchy.

## 5. Components

### Buttons
- **Shape:** 8px radius (matched to platform).
- **Primary:** Brand Red background with white text.
- **Hover:** Slight darkening of the red and a subtle lift.

### Cards
- **Style:** White background, Slate 200 border, 8px radius.

## 6. Do's and Don'ts

### Do:
- **Do** use the Brand Red (#e84848) for all primary actions.
- **Do** use Playfair Display for main titles to maintain brand link.

### Don't:
- **Don't** use greens or indigos as primary accents.
- **Don't** use fluid typography in the admin shell.
